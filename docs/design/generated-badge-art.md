# Generated badge artwork

The member and public profile badge cards use this local set of ten generated
illustrations. Each image is a transparent 320 × 320 WebP in a shared embossed
ivory and amaranth enamel style. The artwork is decorative; the adjacent badge
title and description provide its meaning.
Different thresholds that share a criterion reuse its image; the saved award
revision supplies the criterion used to choose the artwork.

| Criterion | Symbol | Asset |
| --- | --- | --- |
| `STUDY_MINUTES` | Hourglass | `apps/app/public/brand/badges/study-minutes.webp` |
| `STUDY_STREAK_DAYS` | Calendar with seven connected days | `apps/app/public/brand/badges/study-streak-days.webp` |
| `STUDY_GOALS_MET` | Target and centered arrow | `apps/app/public/brand/badges/study-goals-met.webp` |
| `EXERCISE_ANSWERS` | Answer sheet and pencil | `apps/app/public/brand/badges/exercise-answers.webp` |
| `ACTIVITIES_COMPLETED` | Assignment, pen, and check | `apps/app/public/brand/badges/activities-completed.webp` |
| `COMMUNITY_PUBLICATIONS` | Speech shapes and fountain pen | `apps/app/public/brand/badges/community-publications.webp` |
| `LESSONS_COMPLETED` | Open book and check | `apps/app/public/brand/badges/lessons-completed.webp` |
| `TASKS_COMPLETED` | Checked clipboard | `apps/app/public/brand/badges/tasks-completed.webp` |
| `LEARNING_PATHS_COMPLETED` | Winding path and finish pennant | `apps/app/public/brand/badges/learning-paths-completed.webp` |
| `MEETINGS_ATTENDED` | Three learners around a seminar table | `apps/app/public/brand/badges/meetings-attended.webp` |

Generated with the built-in ImageGen tool. Shared prompt: one centered circular
academic achievement medal, refined embossed enamel, warm ivory and deep
amaranth palette with restrained brass accents, transparent background, no
text or watermark. Each asset uses the symbol listed above. Original generated
PNGs remain in the local Codex generated-images directory; the app serves only
the optimized WebP files.
